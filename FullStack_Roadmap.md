# 🚀 16-Week Full-Stack Developer Roadmap

Welcome to your master plan. This document outlines your journey from modern JavaScript basics to deploying a production-ready full-stack application. 

**Tech Stack:** JavaScript/TypeScript, React, Node.js, Express, PostgreSQL, Prisma, and Docker.

---

## 🛠️ Phase 1: Modern JavaScript & Environment (Weeks 1-2)
*Focus: Mastering the core language and getting comfortable with the terminal.*

- [x] **Day 1:** Environment Setup (VS Code, Node.js) & Array Methods (`.map`, `.filter`, `.reduce`)
- [ ] **Day 2:** ES6+ Syntax (Destructuring, Template Literals, Arrow Functions)
- [ ] **Day 3:** Asynchronous JavaScript (Callbacks, Promises, `async/await`)
- [ ] **Day 4:** The DOM & Event Listeners (How JS interacts with HTML)
- [ ] **Day 5:** Fetch API & Handling External Data
- [ ] **Week 2:** Mini-Project — Command Line Application or Vanilla JS Fetch app

## ⚛️ Phase 2: Frontend Development with React (Weeks 3-5)
*Focus: Component-based architecture and state management.*

- [ ] **Week 3:** React Fundamentals (JSX, Components, Props)
- [ ] **Week 4:** State & Lifecycle (`useState`, `useEffect`, Event Handling)
- [ ] **Week 5:** Advanced React (Routing with React Router, Context API, fetching data in React)
- [ ] **Milestone Project 1:** A dynamic frontend-only React application (e.g., Movie Database or Task Tracker).

## ⚙️ Phase 3: Backend Fundamentals (Weeks 6-8)
*Focus: Building your own APIs and understanding servers.*

- [ ] **Week 6:** Intro to Node.js & Express.js (Creating a server, handling HTTP requests)
- [ ] **Week 7:** RESTful API Design (GET, POST, PUT, DELETE, routing, status codes)
- [ ] **Week 8:** Middleware & Error Handling (Testing endpoints with Thunder Client)
- [ ] **Milestone Project 2:** A standalone REST API built with Express.

## 🗄️ Phase 4: Databases & Data Modeling (Weeks 9-11)
*Focus: Storing data persistently using relational databases.*

- [ ] **Week 9:** Intro to Relational Databases (SQL basics, Tables, Relations)
- [ ] **Week 10:** PostgreSQL & Docker (Running a local database container)
- [ ] **Week 11:** Object-Relational Mapping (Integrating Prisma ORM with your Express backend)
- [ ] **Milestone Project 3:** Connecting your Express API to a live PostgreSQL database via Prisma.

## 🔐 Phase 5: Full-Stack Integration & Security (Weeks 12-14)
*Focus: Connecting the frontend to the backend and securing user data.*

- [ ] **Week 12:** Connecting React to Express (CORS, making API calls from the frontend)
- [ ] **Week 13:** Authentication & Authorization (JWTs, Cookies, hashing passwords with bcrypt)
- [ ] **Week 14:** Global State & Protected Routes (Keeping users logged in across page reloads)
- [ ] **Milestone Project 4:** A complete Full-Stack CRUD application with user login.

## 🚢 Phase 6: DevOps & Deployment (Weeks 15-16)
*Focus: Getting your application on the internet for the world to see.*

- [ ] **Week 15:** Preparing for Production (Environment variables, code optimization)
- [ ] **Week 16:** Deployment (Hosting the database on a cloud provider, deploying the Node backend, and hosting the React frontend)
- [ ] **Final Goal:** Add your deployed Full-Stack application to your portfolio!
